## Getting Started

### Local Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/aidzwebstore-dot/primary-school-website.git
   cd primary-school-website
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - No server or build tools required!

### Customization Guide

#### Change School Name
1. Open `index.html`
2. Replace "Bright Future Primary School" with your school name
3. Update the school name in all sections

#### Change Colors
1. Open `styles.css`
2. Modify the CSS variables in the `:root` section:
   ```css
   :root {
       --primary-color: #667eea;      /* Change primary color */
       --secondary-color: #764ba2;    /* Change secondary color */
       --accent-color: #f5576c;       /* Change accent color */
   }
   ```

#### Add Your School Information
- **Contact Details**: Update phone numbers, email, and address in the Contact section
- **School Hours**: Modify the operating hours in the Contact section
- **Faculty**: Add your teachers' information in the Faculty section
- **Programs**: Customize academic programs in the Academics section

#### Update Social Media Links
In the footer section, replace `#` with your social media URLs:
```html
<a href="https://facebook.com/yourschool"><i class="fab fa-facebook"></i></a>
```
